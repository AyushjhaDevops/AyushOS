# AyushOS

A research-oriented 32-bit x86 operating system built from scratch
for learning operating-system internals and experimental research.

## Target

- Architecture: x86 32-bit
- Host OS: Arch Linux
- Language: C
- Assembly: NASM
- Bootloader: GRUB
- Emulator: QEMU
- Debugger: GDB
